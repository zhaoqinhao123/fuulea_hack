☁ fuulea_hack 配置恢复 / PIN 重置

用于忘记 PIN 时恢复云端配置，或在仓库侧重置 PIN。所有解密都在本页完成，密钥不会上传。
等待操作…
找回流程
1. 用管理员密钥或上传时的 Token 解出配置的随机会话密钥；
2. 只用这个密钥重新包裹新 PIN（配置内容 box 完全不动，配置 ID 也不变）；
3. 有写权限的 Token 时直接 PUT 回 config/<id>.json，否则把下方 JSON 手动提交。

仓库管理员也可以在 GitLab CI 里运行 reset-pin 手动任务（需要 CI 变量 ADMIN_KEY、CONFIG_ID、NEW_PIN）。
